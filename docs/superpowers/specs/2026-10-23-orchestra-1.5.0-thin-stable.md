## Product direction

Codex native is the execution and context engine. Orchestra is a small provider-compatible layer for local lifecycle, recoverable work continuity, and factual side-effect/authority boundaries. It must not impose extra model calls, a daemon, a nested Codex instance, global registry, worker RAM reservation or RSI on normal Codex work.

V1 remains the supported stable line. V2 stays beta/experimental in separate Draft PRs.

## Combined 1.5 acceptance

1. **Temporary worktrees.** Create/list/inspect Git worktrees, install local Codex runtime from one checkout, Doctor and isolate runtime state/Work Lease. A failed installation preserves its worktree; no automatic deletion. Git common metadata, including info/exclude, is shared and must not be torn down by another worktree's lifecycle.
2. **Safe uninstall.** Official dry-run and uninstall for both Codex and neutral delegation runtime. Only manifest-owned byte-verified files removed, gated on quiescence and Work Lease. Keep product code, untracked user data, evidence, state, history, rollback backups and other worktrees. Never remove unrelated hooks or shared excludes.
3. **Hostage-chat recovery.** Read-only inspection, factual owner/liveness checks, explicit and bounded recovery for orphaned writer leases. Distinguish LIVE, STALE_RECOVERABLE, STALE_DIRTY and UNKNOWN; dirty artifacts survive. New Codex sessions use factual generation identity without transferring conversation text. No unsafe forced handoff.
4. **Codex hooks.** Port only verified fixes from V2's Codex wire transport, semantics of deny, factual terminalization, and stale-epoch denial following runtime updates. Do not copy the global V2 control plane.
5. **Performance / release quality.** Windows and Linux tests, real install/doctor/uninstall/rollback plus concurrent-worktree fixtures; no V2/AGY direct-work smoke; compare normal overhead against unmodified Codex. CI-first and measured resources.
