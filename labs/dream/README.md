# Dream Lab

Dream is an Orchestra Lab. Its authority is explicitly `NONE`.

Dream may observe, analyze, simulate, replay, and store lab-scoped artifacts. Dream output is advisory: it cannot accept work, grant capabilities, claim Work Leases, mutate product state, or promote itself into acceptance/evidence authority.

Any runtime launcher that exposes Dream functionality is a compatibility surface only and must preserve the zero-authority contract in `labs/lab-authority.mjs`.
